# PassSmith

基于社会工程学信息的密码字典生成工具。填入目标的姓名、生日、手机号等信息，产出一份**针对这个人**的高命中率字典。

相比通用暴力字典，基于个人信息衍生的密码命中率通常高出数倍。用于授权渗透测试。

---

## 亮点

**中文姓名不是简单转拼音**

支持复姓（欧阳 / 司马 / 诸葛）、多音字姓（单 → shan、解 → xie、仇 → qiu）、叠字昵称（sansan / Sansan）、名姓反向（sanzhang）。大小写按音节边界组合出 `zhangsan` / `Zhangsan` / `ZHANGSAN` / `ZhangSan`，不做 `2^8` 的逐字符枚举——那 256 种里 250 种没人用，只会撑大字典。

**组合顺序按真实密码形态排**

0 级纯弱口令 → 1 级单元素衍生 → 2 级双元素 → 3 级三元素。弱口令按真实泄露库频率排序；反向拼接（`123zhangsan`）只保留 3 个最常用项，因为它的真实使用频率远低于 `zhangsan123`，全量展开只会占满字典前段最有价值的位置。

**字典前 100 条比总量重要**

在线爆破受账号锁定限制，实战打法是 Top100 → Top1000 → 全量。内置分档导出一条命令直接产出这三个文件，省去手工切分。

**预估零误差**

5 万条以内直接精确计数（已计入筛选与去重），不是拍脑袋的算术估算。超过阈值才退回估算并明确标注。

**不合法的密码不会进字典**

四道闸门层层拦截，中文、全角字符、emoji、首尾空白一律不得进入。`张三123` 这类在任何真实系统上都登不进去的条目，不会污染字典、拉低命中率。

## 功能

### 输入信息

| 类别 | 字段 |
|------|------|
| 身份 | 中文姓名、英文名、昵称、出生日期 |
| 联系 | 手机号、QQ、微信、邮箱 |
| 证件 | 身份证、工号、学号 |
| 社交 | 伴侣姓名 / 生日、父母姓名、宠物名 |
| 工作 | 公司 / 学校全名与缩写、所在城市、常用 ID |

全部选填，填得越多样典越准。**不填任何信息也能用**——直接导出纯弱口令表。

### 生成规则

| 规则 | 产出示例 |
|------|---------|
| 姓名 + 弱口令 | `zhangsan123`、`zs123456` |
| 姓名 + 生日 | `zhangsan1990`、`zs0115`、`zhang.san_900115` |
| 手机号衍生 | 完整号、后 8 / 6 / 4 位、号段 + 后 4 位 |
| 身份证衍生 | 完整、后 8 / 6 / 4 位、出生日期、尾号 X 大小写对偶 |
| 邮箱前缀 | 去点、点换下划线 / 短横线、首字母大写 |
| 大小写组合 | `zhangsan` / `Zhangsan` / `ZHANGSAN` / `ZhangSan` |
| Leet Speak | `a`→`@`、`e`→`3`、`o`→`0`、`s`→`$` |
| 键盘模式 | `qwerty`、`1qaz2wsx`、`1qaz@wsx`、`!@#$%^` |
| 自定义规则 | `{姓名}{生日年}`、`{邮箱前缀}{弱口令}` 等 20+ 占位符 |

组合深度 0–3 级可调。

### 站点密码策略

四种预设一键套用，适配不同目标系统的密码策略：

| 预设 | 长度 | 要求 | 适用场景 |
|------|------|------|---------|
| 宽松 | 6–20 | 无 | 内网弱策略、靶场、CTF |
| 标准 | 8–20 | 数字 + 字母 + 特殊字符 + 大小写混合 | 等保三级、AD 域、OA |
| 字母数字 | 6–16 | 数字 + 字母，禁特殊字符 | 老系统、工控 |
| 数字 PIN | 4–8 | 纯数字 | 锁屏、支付密码、门禁 |

套用后仍可手动微调长度、复杂度、字符集白名单。

### 导出

- **TXT** — 面向 hashcat / john，不做任何转义、绝不带 BOM
- **CSV** — 面向 Excel，含公式注入防护、前导零保护
- **分片** — 按行数拆成多个文件
- **分档** — 一次产出 Top100 / Top1000 / 全量

### 辅助工具

- **批量生成**：CSV 多目标，每行一个目标，各出一个字典文件
- **字典合并 / 差集**：二次爆破时排除已试过的密码，省账号锁定次数
- **配置模板**：保存 / 加载完整的信息与规则组合
- **生成历史**：记录最近 10 次生成

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

需要 Python 3.9+。依赖只有 `pypinyin`，界面用 PyQt5。

### 打包为独立程序

```bash
pip install pyinstaller
python build.py
```

产物在 `dist/PassSmith/`，`config/` 与 `assets/` 外置在 exe 同级目录——改弱口令列表不必重新打包。

自检：`PassSmith.exe --selftest`（退出码 0 表示资源齐全）。

## 测试

python -m pytest tests/ -q     # 121 项
